# 🌐 Web Full-Stack & Enterprise Portfolio

Portafolio de soluciones web full-stack empresariales, ERPs a medida y sistemas de gestión de negocios con paneles avanzados, inventarios y módulos de facturación.

Si buscas proyectos relacionados con Inteligencia Artificial, APIs de RAG y automatizaciones, visita mi repositorio: [ai-automation-portfolio](https://github.com/LucPinheiro/ai-automation-portfolio).

---

## 🚀 Proyectos y Plataformas Destacadas

### 1. 🔮 KODEXIA (AI & Electronic Music Agency)
Plataforma web y marca conceptual enfocada en la producción de música electrónica, diseño sonoro y generación de experiencias visuales avanzadas asistidas por IA.
- **Repositorio del proyecto:** [kodexia-ai-agency](https://github.com/LucPinheiro/kodexia-ai-agency)

### 2. 📚 FortesHub (Plataforma Académica y de Investigación)
Ecosistema tecnológico avanzado orientado a la comunidad investigadora y científica:
- **Perfil Académico Interactivo (CV Lattes):** Procesamiento automático de currículums en formato XML para centralizar la trayectoria de investigadores.
- **Repositorios de Código:** Espacio estilo GitHub para científicos de datos y programadores (gestión de dependencias, scripts de Python y slugs).
- **Publicaciones y Monetización:** Alojamiento de papers, libros y artículos con metadatos (DOI, ISBN, ISSN) y pasarela de pagos integrada (PIX y BRL).
- **Módulo Corporativo B2B:** Conexión directa entre empresas y talento científico altamente cualificado.
- **Repositorio del proyecto:** [forteshub-academic-platform](https://github.com/LucPinheiro/forteshub-academic-platform)

### 3. 🪵 Casa Art (Solución en Carpintería)
Sistema integral de gestión empresarial, catálogo web y panel ERP con control de inventario y facturación.
- **Repositorio del proyecto:** [casa-art-erp](https://github.com/LucPinheiro/casa-art-erp)

### 4. ⛪ Missão Cristã Alcance
Plataforma web integral con portal institucional y potente panel de administración (ERP/CRM) para secretaría, control de miembros y tesorería.
- **Repositorio del proyecto:** [missao-alcance-portal](https://github.com/LucPinheiro/missao-alcance-portal)

### 5. 🎵 Música y Movimiento
Plataforma web enfocada en la gestión y difusión de proyectos musicales, formativos y eventos artísticos.
- **Repositorio del proyecto:** [musica-y-movimiento-web](https://github.com/LucPinheiro/musica-y-movimiento-web)

### 6. 🎧 StemLoo
Herramienta inteligente de remixes musicales asistida por IA a partir del envío de pistas de audio (*stems*), optimizada para la gestión de derechos de autor y creación sonora.
- **Repositorio del proyecto:** [stemloo-ai-remix](https://github.com/LucPinheiro/stemloo-ai-remix)

### 7. 📄 CVHub (AI Resume Analyzer)
Sistema inteligente de análisis y filtrado de currículums para el matching automático con ofertas de empleo y convocatoria de entrevistas.
- **Repositorio del proyecto:** [cvhub-ai-analyzer](https://github.com/LucPinheiro/cvhub-ai-analyzer)

### 8. 📈 Optimizador SEO & Analítica Web
Sistema de análisis de tráfico y posicionamiento orientado a maximizar el rendimiento y la visibilidad de los sitios web en buscadores.
- **Repositorio del proyecto:** [seo-web-analyzer](https://github.com/LucPinheiro/seo-web-analyzer)

### 9. 📑 Procesador de Documentos PDF
Utilidad avanzada para la limpieza, procesamiento y remoción de marcas en documentos PDF.
- **Repositorio del proyecto:** [pdf-document-processor](https://github.com/LucPinheiro/pdf-document-processor)

### 10. 🎨 Editor Gráfico Web
Aplicación web interactiva para edición de imágenes, eliminación de fondos y manipulación avanzada de objetos.
- **Repositorio del proyecto:** [web-image-editor](https://github.com/LucPinheiro/web-image-editor)

### 11. ✍️ Generador de Logomarcas y Eslóganes
Herramienta asistida por Inteligencia Artificial para la creación automatizada de identidades visuales y eslóganes comerciales.
- **Repositorio del proyecto:** [ai-brand-generator](https://github.com/LucPinheiro/ai-brand-generator)

### 12. 📊 SlideGen AI (Generador de Presentaciones con IA)
Plataforma web asistida por inteligencia artificial orientada a la creación automatizada de presentaciones, documentos y páginas web dinámicas a partir de prompts (inspirada en herramientas tipo Gamma).
- **Repositorio del proyecto:** [slidegen-ai](https://github.com/LucPinheiro/slidegen-ai)

### 13. ⚙️ Odoo Web Suite & AI Generator
Módulo especializado y desarrollo a medida para Odoo ERP:
- **Odoo Web Customizer:** Herramienta para reestructurar y personalizar plantillas web nativas en Odoo según las necesidades de diseño.
- **AI Website Generator:** Integración mediante un botón directo en los ajustes del sitio web de Odoo para generar y desplegar landing pages automatizadas a través de una agencia de IA.
- **Repositorio del proyecto:** [odoo-ai-web-suite](https://github.com/LucPinheiro/odoo-ai-web-suite)
